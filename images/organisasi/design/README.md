# Folder Karya Desain Kominfo BEM PNC

Folder ini disiapkan khusus untuk menyimpan file gambar karya desain grafis yang Anda buat selama menjadi Staff Desain Grafis Departemen Kominfo BEM Politeknik Negeri Cilacap.

Format gambar yang disarankan: `.png` atau `.jpg` / `.jpeg`.

Setelah mengunggah gambar desain Anda ke folder ini, Anda dapat memperbarui path file pada dataset `designWorks` di `index.html`.
